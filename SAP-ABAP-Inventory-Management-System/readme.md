# SAP ABAP inventory Management System

## Project Overview
The project is created using SAP ABAP language in SAP ECC 6.0 system.
The project is used to display the material wise and plant wise stock details.

## Features
• To display the material by plant
• Using the select-options, we can select materials
• To read the data from MARA and MARD tables
• To display the material number and material type
• To display plant and storage location
• To display the quantity of stock which is available for use
• The project uses the internal table and work area
• To display the results in output screen using the write statement

### SAP tables
MARA-General material data
MARD-Storage location data

## ABAP Concepts
PARAMETERS, SELECT-OPTIONS, TYPES AND DATA declaration, INNER JOIN, SELECT AND WHERE clause, Internal tables, LOOP AT, WRITE and SY-SUBRC.

### Development tools
SAP ECC 6.0, SAP GUI, SE38 ABAP Editor,
Visual Studio Code, Git and GitHub
